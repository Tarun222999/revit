IGDB can support

The game’s public context

These sections have direct provider fields and can be normalized behind the existing Supabase boundary.

  • Cover, artwork, screenshots, summary, and storyline
  • Genres, themes, perspectives, and game modes
  • Platforms plus platform- and region-specific release dates
  • Developer, publisher, ratings, age ratings, and videos
  • Game status/type, editions, DLC relationships, websites, and time-to-beat estimates

IGDB does not supply

The player’s private reality

These cannot be copied from the movie flow or inferred from a supported-platform list.

  • Cast or performer credits comparable to TMDB’s Top cast
  • Owned, installed, subscription, or storefront-library status
  • Achievements, save progress, completion percentage, or live hours played
  • Which platform this user chose, their session dates, notes, or rating
  • One universal release date or a guaranteed trailer for every game
